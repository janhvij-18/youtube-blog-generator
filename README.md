YouTube Blog Generator
A Python workflow that turns an educational video transcript into SEO-oriented keyword suggestions, a keyword hierarchy, and a short video script. It uses the Groq API and keeps the transcript as the source of truth for generated content.

Workflow
keyword_legacy.py reads Session_1_no_timestamps.txt, splits it into 500-word chunks, and asks the configured Groq model to extract relevant educational keywords. It writes the results to keywords_output.json.
blog_generator.py removes duplicate keywords, arranges the remaining keywords into a hierarchy, and generates a 180-220 word script using the transcript. It writes keyword_hierarchy.md and final_blog.md.
The keyword suggestions are generated by an AI model from transcript context. They are not validated against search-volume, ranking, or competition data.

Requirements
Python 3.10 or later
A Groq API key
Install the Python packages:

python -m pip install groq python-dotenv

Create a .env file in the project folder with your API key:

GROQ_API_KEY=your_groq_api_key

Do not commit or share the .env file.

Run
Run these commands from the project folder, in order:

python keyword_legacy.py
python blog_generator.py

The transcript file Session_1_no_timestamps.txt must be present in the project folder. Both scripts use the model openai/gpt-oss-120b.

Main Files
keyword_legacy.py: extracts transcript-based keyword suggestions.
blog_generator.py: validates and organizes keywords, then generates the video script.
Session_1_no_timestamps.txt: transcript input.
keywords_output.json: extracted keyword data.
keyword_hierarchy.md: generated keyword hierarchy.
final_blog.md: generated spoken script.
Notes
The script generator uses the transcript as its factual source and rejects unsupported content.
The generated script is checked to be between 180 and 220 words.
Generated results can vary between API calls and should be reviewed before publication.
